# Reverse a String

## Problem Description

Given an input string `A`, the task is to reverse the order of its characters and return the newly formed reversed string.

## Constraints

*   `1 <= |A| <= 10^5` (Length of the string is between 1 and 100,000)
*   String `A` consists only of lowercase English characters.

## Input Format

The first and only argument is a string `A`.

## Output Format

Return a single string denoting the reversed string.

## Example Input and Output

### Example 1

**Input:**
`A = "scaler"`

**Output:**
`"relacs"`

### Example 2

**Input:**
`A = "academy"`

**Output:**
`"ymedaca"`
