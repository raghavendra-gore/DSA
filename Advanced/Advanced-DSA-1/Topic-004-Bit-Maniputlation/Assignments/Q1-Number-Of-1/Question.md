# Count Number of 1 Bits in Binary Representation (Hamming Weight)

## Problem Description

Write a function that takes a non-negative integer `A` and returns the number of 1 bits present in its binary representation. This is commonly known as calculating the Hamming weight.

## Problem Constraints

*   `1 <= A <= 10^9`

## Input Format

The first and only argument contains a single integer `A`.

## Output Format

Return an integer representing the count of 1 bits.

## Example Input

**Input 1:**
Use code with caution.

11
**Input 2:**
6

## Example Output

**Output 1:**
3
**Output 2:**
2

## Example Explanation

**Explanation 1:**
The decimal number 11 is represented as `1011` in binary. It has three 1 bits.

**Explanation 2:**
The decimal number 6 is represented as `110` in binary. It has two 1 bits.
