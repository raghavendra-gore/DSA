# Find the Two Single Occurring Elements in an Array (Two Single Numbers)

## Problem Description

Given an array of positive integers `A`, exactly two integers appear only once, and all the other integers appear exactly twice.

Find the two integers that appear only once.

**Note:** Return the two numbers in ascending order.

## Problem Constraints

*   `2 <= |A| <= 100000` (Size of the array is even, at least 2)
*   `1 <= A[i] <= 10^9`

## Input Format

The first argument is an array of integers of size `N`.

## Output Format

Return an array containing the two single-occurring integers in ascending order.

## Example Input

**Input 1:**

A = [1, 2, 3, 1, 2, 4]
**Input 2:**
A = [1, 2]

## Example Output

**Output 1:**
[3, 4]
**Output 2:**
[1, 2]

## Example Explanation

**Explanation 1:**
The elements `3` and `4` appear only once in the array `[1, 2, 3, 1, 2, 4]`.

**Explanation 2:**
The elements `1` and `2` appear only once in the array `[1, 2]`.
