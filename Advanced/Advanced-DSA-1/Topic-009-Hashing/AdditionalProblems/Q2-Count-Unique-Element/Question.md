# Count Elements with Frequency 1

## Problem Description

You are given an array `A` of `N` integers. Return the count of elements with frequency 1 in the given array.

## Problem Constraints

*   `1 <= N <= 10^5`
*   `1 <= A[i] <= 10^9`

## Input Format

*   First argument `A` is an array of integers.

## Output Format

*   Return an integer representing the total count of elements that appear exactly once.

## Example Input

### Input 1:

A = [3, 4, 3, 6, 6]

### Input 2:
A = [3, 3, 3, 9, 0, 1, 0]

## Example Output

### Output 1:
1

### Output 2:
2

## Example Explanation

### Explanation 1:
Only the element `4` has a frequency of 1.

### Explanation 2:
The elements `9` and `1` have a frequency of 1.
